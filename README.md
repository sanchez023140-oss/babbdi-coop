# BABBDI Co-op

Фанатский кооперативный мод для **BABBDI 1.2.3**: сетевой кооп на 2–3 игроков, синхронизация
аватара, район Сталин в море за дамбой и аркадные автоматы с дуэлями.

> Скачать: **[последний релиз](https://github.com/sanchez023140-oss/babbdi-coop/releases/latest)** —
> архив `BabbdiCoop-vX.Y.Z.zip`, ~120 МБ.

## Что умеет

- **Кооп на 2–3 игроков** — поза, анимация, предметы в руках, трюки, всё синхронно.
- **Steam-транспорт** — лобби по кнопке, без IP, Radmin и проброса портов. Или обычный UDP по IP.
- **Район Сталин** — 36 домов с интерьерами и лестницами, крытые мосты, Дом Советов,
  мемориал, часовая башня, 7 персонажей на крыше, Ми-26 на дамбе.
- **Аэрохоккей** на двоих с сохранением счёта на табло.
- **14 аркадных автоматов**: Динозаврик, Арканоид, Понг, Змейка + три дуэльных
  (Понг до 7, Арканоид с мусорными рядами, Змейка до 3 раундов).
- **Леталка** с поднятым потолком до 600 м и увеличенной картой (×2 по площади, ×2 по высоте неба).

## Установка

1. **BABBDI 1.2.3** — itch.io или Steam.
2. **[BepInEx 5.4.23.2 x64](https://github.com/BepInEx/BepInEx/releases)** — распаковать в папку игры.
3. Распаковать архив мода туда же. Появятся:
   ```
   BepInEx\plugins\BabbdiCoop.dll
   BepInEx\plugins\BabbdiCoop\   (модели, арт, звуки)
   ```
4. Запустить `Babbdi.exe` и проверить `<игра>\BepInEx\LogOutput.log`:
   `BabbdiCoop v0.10.48 loaded`.

## Подключение

### Steam (рекомендуется)

В `BepInEx\config\com.babbdi.coop.cfg`, секция `[Net]`, **у обоих**:

```ini
Transport = steam
```

- Хост: **F5** → создаётся лобби.
- Второй игрок: **F10** → выбрать лобби в списке → **Enter**.
- NAT и порты не важны: Steam сам находит маршрут.

### По IP (UDP)

```ini
[Net]
Transport = udp
JoinIP = 192.168.0.12
Port = 7777
```

Хост — **F5**, клиент — **F6**. На хосте разрешить входящий UDP 7777.

**Версии мода должны совпадать** — иначе HUD напишет красным «ВЕРСИИ НЕ СОВПАДАЮТ».

## Управление

| Клавиши | Действие |
|---|---|
| F5 / F6 / F7 | хост / подключиться / отключиться |
| F9 / F10 | пригласить друга / список лобби |
| E / F у автомата | играть / дуэль |
| B / V | стойка на руках / сальто |

## Сборка из исходников

```powershell
cd BabbdiCoop
powershell -ExecutionPolicy Bypass -File build.ps1     # соберёт и скопирует DLL в игру
cd ..
dotnet run --project Tests                             # 8 офлайн-проверок правил
```

`BabbdiCoop.csproj` ожидает игру в `E:\858\BABBDI_WINDOWS_1.2.3` — путь задан в `<GameDir>`,
поменяйте под себя.
